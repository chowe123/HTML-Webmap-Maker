# Peel street basemap

`Peel-StreetMap-z15.mbtiles` — Esri World Street Map clipped to the Region of Peel, zooms 0-15 (41.4 MB, 4,389 tiles).
Bounds: -80.08, 43.50, -79.53, 43.98.
Single file — load it in the maker via **Local MBTiles basemap**.
